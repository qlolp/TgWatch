# TG Монитор

Android-приложение, которое постоянно проверяет, доступен ли Telegram (`https://api.telegram.org/`).

- В строке состояния всё время висит значок:
  - ✈️ **бумажный самолётик** — Telegram доступен;
  - ❗ **круг с восклицательным знаком** — Telegram недоступен или нет интернета.
- Когда связь пропадает, телефон вибрирует тремя длинными импульсами, **не чаще одного раза в 5 минут**.
- Если связь потеряна надолго, вибрация повторяется каждые 5 минут, пока связь не вернётся.
- Приложение запускается само после перезагрузки телефона.
- Поддерживается Android 8.0 и новее.

## Как получить APK

Выбери один из двух способов.

### Способ 1. GitHub, ничего устанавливать не нужно

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху нажми **+** → **New repository**. Назови его, например, `TgWatch`, выбери **Private** и нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив `TgWatch.zip`. Открой папку `TgWatch` и перетащи в окно браузера **всё её содержимое**, включая папку `.github`.
   На Mac скрытые папки показываются сочетанием `Cmd + Shift + .`.
5. Внизу нажми **Commit changes**.
6. Открой вкладку **Actions**. Там запустится сборка **Build APK**, она идёт примерно 3–6 минут.
7. Когда появится зелёная галочка, открой эту сборку. Внизу, в разделе **Artifacts**, скачай `TgWatch-apk`. Внутри архива лежит файл `app-debug.apk`.

### Способ 2. Android Studio на компьютере

1. Скачай и установи Android Studio: <https://developer.android.com/studio>. Настройки установки оставь по умолчанию.
   При первом запуске она сама скачает Android SDK, это займёт 1–3 ГБ.
2. Распакуй `TgWatch.zip`.
3. В Android Studio нажми **Open** и выбери папку `TgWatch`. На вопрос о доверии проекту ответь **Trust Project**.
4. Подожди, пока внизу закончится синхронизация Gradle. Первый раз это 5–15 минут.
5. Выбери в меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   В новых версиях Android Studio этот пункт называется **Build → Generate App Bundles or APKs → Generate APKs**.
6. Когда справа внизу появится уведомление, нажми в нём **locate**. Нужный файл:
   `TgWatch/app/build/outputs/apk/debug/app-debug.apk`

#### Если Android Studio выдала ошибку при синхронизации

- **Ошибка про версию Java** (`Unsupported class file major version`, `Incompatible Gradle JVM`):
  открой **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**.
  Выбери JDK версии 17 или 21. Если такой нет в списке, нажми **Download JDK…** и скачай версию 17.
  Затем нажми **File → Sync Project with Gradle Files**.
- **Предложение обновить Android Gradle Plugin** (AGP Upgrade Assistant): его можно просто закрыть.
  Проект собирается и на текущих версиях.

## Установка на телефон

1. Перекинь `app-debug.apk` на телефон любым способом: через «Избранное» в Telegram, по кабелю или через облачный диск.
2. Открой файл на телефоне. Android попросит разрешить установку из этого источника: разреши.
3. Google Play Protect может предупредить о неизвестном приложении. Нажми **Подробнее → Всё равно установить**.
   Предупреждение появляется потому, что приложение не из Play Маркета.

## Первый запуск: обязательно

1. **Разреши уведомления.** Без них значка в строке состояния не будет.
2. Нажми кнопку **«Разрешить работу без ограничений»** и подтверди.
   Иначе Android «усыпит» проверки, когда экран выключен.
3. На некоторых телефонах нужно дополнительно снять ограничения в настройках:
   - **Xiaomi / Redmi / POCO**: Настройки → Приложения → TG Монитор → включи **Автозапуск**. Там же в разделе **Контроль активности** выбери **Нет ограничений**.
   - **Samsung**: Настройки → Приложения → TG Монитор → Батарея → **Без ограничений**. Также убери приложение из списка «Спящие приложения».
   - **Huawei / Honor**: Настройки → Батарея → Запуск приложений → TG Монитор → **Управлять вручную** и включи все переключатели.
4. Проверь, что всё работает: включи режим полёта. Через несколько секунд значок сменится на ❗ и телефон завибрирует.
   Выключи режим полёта, и значок снова станет самолётиком.

## Как это работает

- Каждые 30 секунд приложение отправляет HTTPS-запрос на `https://api.telegram.org/`. Интервал можно поменять на экране приложения: 15 с, 30 с, 1 мин или 2 мин.
- Любой ответ сервера означает, что Telegram доступен.
- Если сервер не ответил за 10 секунд или соединение оборвалось, через 3 секунды идёт повторная попытка. Только после второй неудачи связь считается потерянной. Так случайные сбои не вызывают ложных тревог.
- Когда телефон теряет или находит сеть, проверка запускается сразу, не дожидаясь интервала.
- Если на телефоне включён VPN, проверка идёт через него, то есть так же, как работает сам Telegram.
- Переключатель **«Не давать телефону засыпать»** включён по умолчанию. С ним проверки идут и при выключенном экране, но батарея расходуется быстрее, ориентировочно на несколько процентов в сутки.
  Если выключить переключатель, при погашенном экране проверки будут приостанавливаться.
- На экране приложения есть журнал: там видно, когда связь пропадала и когда возвращалась.

## Где что поменять в коде

| Что | Файл | Что искать |
|---|---|---|
| Адрес проверки | `app/src/main/java/ru/tgwatch/MonitorService.kt` | `CHECK_URL` |
| Пауза между вибрациями | там же | `VIBRATION_GAP_MS` |
| Таймаут запроса | там же | `TIMEOUT_MS` |
| Рисунок вибрации | `app/src/main/java/ru/tgwatch/Vibe.kt` | `PATTERN` |
| Значки | `app/src/main/res/drawable/` | `ic_stat_ok.xml`, `ic_stat_fail.xml` |
