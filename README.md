# TG Монитор

Android-приложение, которое постоянно проверяет, доступен ли Telegram
(`api.telegram.org`; если он не ответил за 1,5 с — ещё `web.telegram.org` и `core.telegram.org`).

- В строке состояния всё время висит значок:
  - ✈️ **бумажный самолётик** — Telegram доступен;
  - ❗ **мигающий круг с восклицательным знаком** — Telegram недоступен, а остальной интернет работает
    (уведомление становится красным);
  - ☁️ **мигающее перечёркнутое облако** — нет интернета вообще (уведомление оранжевое).
- Пока связи нет, в уведомлении тикает секундомер: сколько уже без Telegram.
- Когда **именно Telegram** недоступен, телефон вибрирует тремя длинными импульсами,
  **не чаще одного раза в 5 минут**. Вибрацию при потере интернета можно включить отдельно.
  При возврате связи — короткий импульс (настраивается). Тихие часы (по умолчанию 23:00–08:00,
  время можно изменить) отключают вибрацию.
- Проверка по умолчанию каждые **15 секунд**, а пока связи нет — каждые **10 секунд**.
  При выключенном экране к каждой проверке телефон будит системный будильник, поэтому
  проверки не замирают во сне (в глубоком сне Android может делать их реже).
  Ответ ждём **5 секунд**. Ответ **5xx** считается недоступностью (не «всё ок»).
- Короткое переключение между Wi‑Fi и мобильной сетью не считается потерей связи.
- На экране: карточка статуса, доступность Telegram за сутки (без учёта offline),
  сводка сбоев, график за час (тап по столбику — детали) и журнал.
- Если проверка устарела (служба перезапускалась) — показывается «последний раз…», а не ложный OK.
- Чеклист первого запуска сверху: уведомления и работа без ограничений.
- Светлая и тёмная тема (по настройке телефона).
- Плитка **Telegram** в быстрых настройках шторки.
- Виджет **Статус Telegram** на рабочий стол: цветная плашка со статусом и временем ответа.
- Автозапуск после перезагрузки (в т.ч. QUICKBOOT на Xiaomi).
- Поддерживается Android 8.0 и новее.

**Готовый APK:** <https://github.com/qlolp/TgWatch/releases/latest/download/TgWatch.apk>.
Открой эту ссылку прямо на телефоне. Файл обновляется автоматически после каждого изменения кода.

## Как получить APK

Выбери один из двух способов.

### Способ 1. GitHub, ничего устанавливать не нужно

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху нажми **+** → **New repository**. Назови его, например, `TgWatch`, выбери **Private** и нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив `TgWatch.zip`. Открой папку `TgWatch` и перетащи в окно браузера **всё её содержимое**, включая папку `.github`.
   На Mac скрытые папки показываются сочетанием `Cmd + Shift + .`.
5. Внизу нажми **Commit changes**.
6. Открой вкладку **Actions**. Там запустится сборка **Build APK**, она идёт примерно 3–6 минут.
7. Когда появится зелёная галочка, открой эту сборку. Внизу, в разделе **Artifacts**, скачай `TgWatch-apk`. Внутри архива лежит файл `app-debug.apk`.

### Способ 2. Android Studio на компьютере

1. Скачай и установи Android Studio: <https://developer.android.com/studio>.
2. Распакуй `TgWatch.zip`, открой папку в Android Studio (**Trust Project**).
3. Дождись синхронизации Gradle.
4. **Build → Build APK(s)** / **Generate APKs**.
5. Нужный файл: `TgWatch/app/build/outputs/apk/debug/app-debug.apk`

#### Если Android Studio выдала ошибку про Java

Открой **Settings → Build Tools → Gradle → Gradle JDK** и выбери JDK 17 или 21.

## Установка на телефон

1. Перекинь APK на телефон.
2. Разреши установку из этого источника.
3. Google Play Protect может предупредить — **Подробнее → Всё равно установить**.

## Первый запуск: обязательно

Вверху экрана появится чеклист, пока не сделаешь оба пункта:

1. **Разреши уведомления.**
2. Нажми **«Разрешить работу без ограничений»**.
3. На Xiaomi / Samsung / Huawei и др. — дополнительная подсказка прямо в приложении
   (или кнопка «Открыть настройки приложения»).

Проверка: режим полёта → значок ❗ (вибрация только если включена «при потере интернета»).
Для проверки вибрации Telegram выключи Wi‑Fi/мобильный и подожди, либо используй кнопку «Проверить вибрацию».

## Как это работает

- Каждые **15 секунд** (по умолчанию) — HTTPS к `api.telegram.org` (и параллельно запасным хостам).
  Интервал: **10 с / 15 с / 30 с / 1 мин / 2 мин**.
- Успех = HTTP **1xx–4xx** (сервер ответил). **5xx** = Telegram недоступен.
- Сначала HEAD; если не принимает — GET.
- При неудаче через **1,5 с** повтор; параллельно проверяются контрольные сайты
  (Яндекс, Mail.ru, VK, Google).
- Wake lock берётся **только на время проверки**, не на весь день.
- Процент «Telegram за сутки» = успешные / (успешные + сбои Telegram), минуты без интернета не портят цифру.

## Где что поменять в коде

| Что | Файл | Что искать |
|---|---|---|
| Адрес проверки | `MonitorService.kt` | `CHECK_URL`, `TG_URLS` |
| Что считать успехом HTTP | `ProbeRules.kt` | `isReachableHttpCode` |
| Пауза между вибрациями | `MonitorService.kt` | `VIBRATION_GAP_MS` |
| Таймаут запроса | `MonitorService.kt` | `TIMEOUT_MS` |
| Рисунок вибрации | `Vibe.kt` | `ALARM`, `RECOVERY` |
