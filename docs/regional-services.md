# Региональная доступность сервисов

На главном экране телефона откройте «Региональная доступность сервисов» и включите нужные профили.
По умолчанию они выключены. Telegram, Matrix, WhatsApp Web и собственный HTTPS сохраняют свои настройки,
историю и интервалы; новые профили не меняют их статистику.

| Профиль | Публичная точка проверки | Что требует отдельной проверки |
| --- | --- | --- |
| YouTube | `https://www.youtube.com/` | Воспроизведение конкретного видео |
| Gemini | `https://gemini.google.com/` | Вход в аккаунт и выполнение запроса |
| Notebook | `https://notebook.google.com/` | Открытие блокнота и генерация |
| Antigravity | `https://antigravity.google/` | Вход, работа приложения/IDE и запрос к модели |
| ChatGPT / dots | `https://chatgpt.com/dots/home` | Вход и доступ к конкретной функции dots |

«Публичный сайт отвечает» означает только ответ сайта. Вход, CAPTCHA, ограничение частоты, сетевые ошибки
и неопределённые ответы показаны отдельно. Обычный 403/451,404 по закрытому маршруту или другая страна
Cloudflare не считаются доказательством геоблокировки.

Для предупреждения нужны два явных региональных ответа одного сервиса в одном подключении с интервалом
не меньше 15 секунд. Первый ответ назначает подтверждающую проверку. Обычно проверки идут раз в 5 минут,
при выключенном экране или экономии заряда — раз в 10 минут. Doze и ограничения телефона могут задержать их;
рядом с результатом всегда указан его возраст. Смена сети/настроек и выключение профиля отменяют старое
свидетельство; запоздалый ответ не публикуется.

Есть отдельный системный канал региональных уведомлений. Действуют общие тихие часы, «не беспокоить»,
«Заглушить все тревоги на час» и собственные плановые паузы регионального экрана. Паузы исторических целей
относятся к тем целям, для которых заданы. На один подтверждённый инцидент приходит одно уведомление;
между уведомлениями не меньше 5 минут. Ошибка сети не считается восстановлением сервиса.

Страна выхода показана с флагом, названием, источником Cloudflare и возрастом. Её можно обновить вручную.
Старые данные, другая сеть, перезагрузка, перевод часов назад и неудачное обновление не дают текущего
подтверждённого флага. При раздельной маршрутизации/VPN путь к Cloudflare может отличаться от пути к сервису.
Страна — контекст, а не проверка региональных правил каждого сервиса.

Результаты региональных проверок остаются в памяти процесса. Настройки и подавление повторных тревог
хранятся локально; после восстановления бэкапа все региональные профили выключены, их состояние очищено.
Сырые ответы, IP-адреса, перенаправленные URL, cookies и данные аккаунтов не сохраняются и не экспортируются.

## Mac

Телефон не измеряет подключение Mac. Утилиту нужно запускать на каждом компьютере отдельно.
В скачанном репозитории откройте двойным щелчком [TgWatch-services.command](../tools/TgWatch-services.command).
Нужен Python 3.10+; дополнительных библиотек утилите не требуется. Окно Terminal остаётся открытым,
`Ctrl-C` останавливает мониторинг. Для долгих проверок Mac должен оставаться включённым.
LaunchAgent, расширение браузера и автозапуск не устанавливаются.

Для выбора сервисов и машинного отчёта доступны команды из корня репозитория:

```bash
python3 scripts/regional-services.py --json
python3 scripts/regional-services.py --watch --notify --service gemini --service dots
```

CLI по умолчанию выбирает пять профилей; `--service` можно повторять. `--interval` принимает 300–3600 секунд.
Утилита использует маршрут ОС, включая системный VPN, без cookies и прокси из переменных окружения.
Прокси, заданный только внутри браузера, может использовать другой выход: тогда нужна проверка вкладки ниже.

Перед и после запроса проверяются маршрут и отпечаток выхода. Исходный IP не попадает в отчёт/файл;
отпечаток живёт только в памяти. Смена выхода отбрасывает ответ, отсутствие сетевого контекста не позволяет
объединять его в тревогу. Публичный запрос исполняется в отдельном завершаемом процессе с бюджетом 9 секунд,
ответ ограничен 32 КиБ. Системные уведомления опциональны (`--notify`) и требуют разрешения Terminal/macOS.
При новом запуске CLI подтверждение начинается заново; длительные данные и история не записываются.

## Проверка в открытой вкладке

Откройте локальный файл [regional-browser-bookmarklet.html](../tools/regional-browser-bookmarklet.html),
перетащите кнопку на панель закладок и нажмите сохранённую закладку на странице сервиса.
Помощник один раз читает видимый текст этой вкладки и показывает локальный результат.
Не читает cookies/хранилище и не делает сетевых запросов; данные не передаются приложению или CLI.
Это отдельное наблюдение текущей сессии, оно не смешивается с телефонными результатами.

Если явной ошибки нет, результат — «Доступ к функциям не подтверждён». Для окончательной проверки
запустите видео, отправьте запрос Gemini, откройте/используйте блокнот, выполните действие dots или запрос
в Antigravity. Страница загрузки IDE не проверяет её модельный сервис.
Если политика страницы/браузера блокирует закладку, используйте ручную проверку без изменения защиты.

Регион может зависеть от аккаунта, возраста, подписки и администраторских правил.
Основания и актуальные правила: [Antigravity FAQ](https://antigravity.google/docs/faq/),
[Gemini Notebook](https://support.google.com/gemininotebook/answer/16164461),
[страны ChatGPT](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries).
TgWatch не использует списки стран как автоматический вердикт.

## English

Enable each optional public profile on the phone's regional-services screen. Only two explicit region
responses at least15seconds apart on one current connection can trigger an alert; generic403/451, sign-in,
CAPTCHA, a country flag and public-site responses never certify account features or an IP-only cause.
Intervals are5/10minutes; global quiet/mute/DND, a dedicated channel and regional maintenance windows apply.
Restore disables these device-local profiles. Existing target histories/backup schemas remain intact.

Run `tools/TgWatch-services.command` on each Mac (Python 3.10+) for foreground monitoring, or use the CLI
examples above. Stop with Ctrl-C; nothing installs at startup. Safe JSON contains enums, time and country,
with no raw responses or IPs. Route/egress changes break confirmation. macOS notifications are optional.
Use the local bookmarklet installer for one manually invoked visible-error check in your browser session;
normal page content remains unverified. Test playback/inference/dots/IDE actions in the service itself.
