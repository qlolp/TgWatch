# Сверка ветки cline и завершение 1.15.0

Исходный main: `55d6834c1c1f280d6fb60d3131a5bdd15dfd58c0`.
Проверенная ветка `cline/8j8mmkrk`: `106ed00ea3eb6a05706c156aec83c3b94f60fa03`;
три самостоятельных коммита поверх старой базы. Изменения перенесены выборочно
поверх текущей 1.15, история сохраняется вторым родителем интеграционного коммита.

## Включено

- IPv4 и IPv6 для всех пяти production DC. Адреса сверены с `kBuiltInDcs` и
  `kBuiltInDcsIPv6` официального Telegram Desktop. Primary pool ограничен 16 workers:
  13 параллельных Telegram-проб и место для трёх controls. EXTRA сохраняет свой пул.
- `User-Agent` берёт версию из генерируемого `BuildConfig`.
- Dependabot для Gradle, GitHub Actions и Python; полные commit SHA действий,
  wrapper validation, hash-locked release tooling и явные job timeouts.
- Дополнительная проверка обновления с последнего стабильного опубликованного
  предшественника, наряду с неизменяемой 1.10.47. Выбор не включает draft/prerelease;
  проверяются выбранные assets, checksum, сертификат и фактическая версия APK.
- Перед публикацией повторно проверяются исходный SHA-256 подписанных байтов,
  production-сертификат и версия APK. Эти гарантии текущего main сохранены.
- Согласованы README, английская инструкция, contributing и статус старого аудита.

Тесты проверяют доступность через каждое семейство, параллельный допуск всех
13 primary-проб, HTTP-заголовок, изоляцию EXTRA и границы выбора upgrade baseline.
Результат CI следует сверять по точному commit в GitHub Actions; этот документ
сам по себе не объявляет публикацию APK или успешную проверку.

## Остальные изменения старой ветки

- R8 и изменение разрешения exact alarms требуют самостоятельной проверки
  поведения release-сборки, OEM и пользовательского согласия; в эту сверку не входят.
- Throttle `Prefs.saveLastState` из прототипа учитывал только status/since:
  меняющиеся интервалы и состояние вибрации могли оставаться несохранёнными,
  а `clearLastState` не сбрасывал throttle. Durable persistence текущего main сохранена.
- OSV `database_state` в прототипе вычислялся до заполнения наблюдённых записей;
  эта недостоверная отметка не переносится. Действующий audit остаётся прежним.
- Изменения event actions, summary, state refresh и старые version/backup/UI
  файлы не заменяют исправления 1.13.2–1.15. Исходный код прототипов доступен
  через сохранённого merge-родителя.

`claude/project-thread-s0ejzl` сохраняется отдельно для следующих PR.
Опубликованные версии и assets не перезаписываются; F-Droid остаётся кандидатом.
