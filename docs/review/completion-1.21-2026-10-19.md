## Что исправлено

- **Сетевая статистика.** В RU/EN явно указан местный календарный период:
  сегодня либо календарные дни, включая сегодня. Основная доступность сохраняет
  скользящее окно 24 часа/7 суток; проценты по числу проверок не выдаются за долю
  доступного времени. Формат дневных счётчиков не менялся. Проверены период недели
  и локальная дата на переходе DST/полночь.
- **Detekt baseline.** Сравнивается множество ID с базой PR или предыдущим commit
  push, а не только количество. Замена старого замечания новым и повторное добавление
  удалённого ID запрещены. Пустой исправленный baseline допустим, недоступная база
  считается ошибкой. Есть CLI-проверки настоящего Git commit и отдельного XML.
  Сам `config/detekt/baseline.xml` не изменён.
- **Журнал падений.** Сохраняются фиксированные роли потоков и проверенные метаданные
  кода. Классы разрешаются без инициализации в ограниченных namespaces, имена методов
  проверяются по объявленным методам; неизвестные значения заменяются безопасными
  обозначениями. Файлы исходников проверяются относительно имени класса, пути не
  копируются. Одна политика действует при записи, чтении старого журнала и на границе
  JSON-экспорта. Проверены canary-значения в именах потоков, путях, искусственных
  классах/методах и вручную созданном диагностическом snapshot.
- **Выбор целей вебхука.** Доставка всех четырёх целей уже существовала; добавлен
  пользовательский фильтр событий и heartbeat. Он не включает мониторинг.
  Старые настройки сохраняют все четыре цели, пустой набор выключает автоматическую
  доставку, явный тест продолжает работать. Фильтр хранится в credential-protected
  файле, исключён из Direct Boot и переносимых настроек. Смена выбора меняет поколение,
  отменяет устаревшие решения и не освобождает физический слот до завершения запроса.
  Один HTTPS-адрес, лимиты, форматы TEXT/JSON v1/v2 и точный payload сохранены.

Рекомендации для Home Assistant уточнены: готовые примеры выбирают Telegram явно,
для других целей нужны соответствующие service-ID checks и отдельные entities.
