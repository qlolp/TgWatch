# E. Виджеты и обмен статусом

Статус: проект для согласования. Зависимости: C и D из [программы развития](2026-10-17-growth-design.md).

## Виджеты

Сохраняется RemoteViews без миграции на Glance. Старый widget id автоматически
показывает Telegram. Для новых экземпляров пользователь выбирает одну из четырёх
целей; этот выбор относится к appWidgetId, а не ко всему приложению.

Компактный режим 3x1: статус, возраст измерения, задержка, кнопка проверки.
Расширенный режим 3x2 и больше: дополнительно последний успех, покрытие за сутки,
мини-график за последние шесть часов и кнопка «Заглушить цель на час».
Размер выбирается по appWidgetOptions, без искусственного растягивания текста.

Данные берутся из immutable TargetSnapshot и фонового агрегата. Проверки и
чтение всей истории не запускаются из RemoteViews rendering. Обновления
ограничиваются изменением содержимого и прежним пяти минутным redraw ceiling;
кэш имеет ключ appWidgetId/target, поэтому один виджет не подавляет другой.

CHECK_NOW использует общий target admission. Если мониторинг выключен, открываются
настройки цели, а не запускается скрытый монитор. Mute сохраняется durable перед
подтверждением, затрагивает выбранную цель; глобальный mute остаётся сильнее.
PendingIntent immutable, explicit и различается по widget/action/target.

Удалённая/не настроенная цель и закрытый credential storage имеют явные состояния.
Никакой старый зелёный статус не выдаётся за свежий при stop/reboot/restore.
Кнопки имеют доступные названия, состояние не передаётся одним цветом.

## Карточка для отправки

Кнопка «Поделиться статусом» открывает предпросмотр и системный Sharesheet.
Пользователь выбирает текст или PNG, по умолчанию включён последний час.
Карточка содержит название типа сервиса, измеренный статус, время/часовой пояс,
свежесть, задержку, покрытие и небольшой график. Снимок после stop показывает,
что мониторинг остановлен. Без истории карточка остаётся доступной с no data.

Пользовательская подпись цели по умолчанию заменяется «Свой сервис»; URL, IP,
SSID, токены, журналы, тела ответов и список DC не попадают в изображение/текст.
Предпросмотр показывает точные отправляемые данные, ничего не отправляется самó.
PNG создаётся в cache, передаётся FileProvider content URI с временным read grant,
старые файлы удаляются через сутки и при следующем запуске генератора.

Рендер выполняется в фоне, Bitmap ARGB_8888 ограничен 1 024x1 024 и четырьмя MiB
пикселей. Текстовая
версия доступна всегда и не зависит от возможности открыть картинку.

## Критерии приёмки

- Два виджета разных целей независимо обновляются, проверяются и заглушаются.
- Resize/rotation launcher, app update, reboot, restore, locked storage и stop.
- PendingIntent одного экземпляра не выполняет действие другого.
- Медленная история не блокирует receiver/main и не подменяет актуальный snapshot.
- PNG и текст не содержат fixtures с URL/token/SSID/custom label; content URI
  доступен получателю с grant, но не экспортирует каталог приложения.
- Preview и share используют один snapshot; большие шрифты, TalkBack, светлая и
  тёмная темы не теряют подписи, график имеет текстовое описание.
