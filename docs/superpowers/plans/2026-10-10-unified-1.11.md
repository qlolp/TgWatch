# TgWatch unified 1.11 implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Preserve approved scope and report fresh evidence.

**Goal:** Complete both 1.10 feature sets on current main with backward compatible imports.

**Architecture:** Preserve the two Git parent histories. Use one typed snapshot and replay transaction; read both old portable formats and write one version2 envelope. Independent files may be reconciled concurrently with one coordinator owning Gradle, staging and commits.

**Tech Stack:** Kotlin/JCA, Android26+, Gradle8.10.2/JDK17, Python3, CycloneDX/Trivy/OSV.

**Spec:** docs/superpowers/specs/2026-10-10-unified-1.11-design.md

## Global constraints

No signing key rotation or Secrets changes. Preserve native UI, opt-ins, Direct Boot, seven-day retention and probe deadlines. New archives require12..256-character passwords; imports support both1.10 formats. Shared files have one owner; coordinator alone runs Gradle and commits.

## Review focus

Published-v1 and local-v1 archives must migrate event fallback/minutes correctly; pending journals replay before service starts. UNKNOWN newest epochs cannot revive archived statistics. Event channels retain user sound overrides and quiet/DND behavior. Production signing helper never accepts an unexpected certificate. Release reruns keep immutable evidence and a stale run cannot replace latest.
