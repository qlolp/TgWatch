# E — Widgets and sharing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить независимые виджеты целей и безопасную карточку статуса.

**Architecture:** RemoteViews читают кэшированный snapshot; share capture и renderer работают отдельно от monitor worker. Действия всегда содержат target/widget identity и используют общий admission.

**Tech Stack:** Kotlin/JVM 17, Android Views, Gradle 8.14.6, AGP 8.13.2, Kotlin 2.4.21, JUnit 4; дополнения указаны в задачах.

**Spec:** [Утверждённая спецификация](../specs/2026-10-17-surfaces-design.md), [общие ограничения](../specs/2026-10-17-growth-design.md).

## Global Constraints

- Телефон: Android API 26+, compile/target API 35; Kotlin и существующий Views UI.
- Один foreground-сервис; нет сервера автора, учётной записи или фоновой телеметрии.
- Дополнительные цели и внешние интеграции выключены по умолчанию.
- Недоступность измерения, отсутствие сети и измеренный сбой сервиса различаются.
- `claude/project-thread-s0ejzl` не изменяется, не удаляется и не используется как рабочая ветка.
- Существующие API v1, виджет Telegram и чтение бэкапов v1/v2 сохраняются.
- Новые пользовательские строки добавляются на русском и английском.
- RemoteViews; компактный режим3x1, расширенный3x2; graph шесть часов.
- Share default один час; Bitmap ARGB_8888<=1 024x1 024 и4 MiB.
- Share cache TTL24h; отправка только после явного предпросмотра.

## Review Focus

- Два виджета разных целей — PendingIntent и redraw не пересекаются (Task 1).
- Widget id повторно использован после удаления — старая цель не выполняет действия (Task 1).
- Stop/reboot/locked storage — зелёный старый снимок не выдаётся за текущий (Task 1).
- Личные URL/token/label в данных — ничего не входит в share allowlist (Task 2).
- Поддельный content URI/path traversal/старый grant — доступ только к созданному PNG (Task 2).
