# D — Latency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить честные перцентили, локальные DC-тренды и управляемые пороги.

**Architecture:** Scalar summaries используют сохранённые observations; новые DC details идут в ограниченные локальные buckets. UI и alerts читают immutable series выбранной цели и revision.

**Tech Stack:** Kotlin/JVM 17, Android Views, Gradle 8.14.6, AGP 8.13.2, Kotlin 2.4.21, JUnit 4; дополнения указаны в задачах.

**Spec:** [Утверждённая спецификация](../specs/2026-10-17-latency-design.md), [общие ограничения](../specs/2026-10-17-growth-design.md).

## Global Constraints

- Телефон: Android API 26+, compile/target API 35; Kotlin и существующий Views UI.
- Один foreground-сервис; нет сервера автора, учётной записи или фоновой телеметрии.
- Дополнительные цели и внешние интеграции выключены по умолчанию.
- Недоступность измерения, отсутствие сети и измеренный сбой сервиса различаются.
- `claude/project-thread-s0ejzl` не изменяется, не удаляется и не используется как рабочая ветка.
- Существующие API v1, виджет Telegram и чтение бэкапов v1/v2 сохраняются.
- Новые пользовательские строки добавляются на русском и английском.
- Окна: 1 час, 24 часа, 7 дней; small sample при n<20.
- DC buckets 15 минут, семь дней, максимум16 endpoint ids/672 buckets на id/10 752 всего.
- Порог 500..5 000 ms с шагом100; default1000, clear60%, три проверки, cooldown30 минут.
- DC aggregates локальные и не входят в portable backup v3.

## Review Focus

- Пропавшие медленные DC не превращаются в нулевые задержки (Tasks 1–2).
- n=0/1/19/20 и Long.MAX_VALUE — корректные null/sample/mean/rank (Task 1).
- Rollback и обновление адреса DC — отдельные epochs/revisions, без смешения (Task 2).
- Повреждённый bucket/переполнение counter — мониторинг живёт, метрика unavailable (Task 2).
- UNKNOWN/смена порога/quiet/mute — streak не создаёт ложный новый slow/recovery (Task 3).
