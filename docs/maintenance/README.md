## Завершённые ветки

[merged-branches.json](merged-branches.json) сохраняет имена и полные SHA веток,
чьи вершины уже входят в зафиксированный `main`. Поэтому удаление такого указателя
не удаляет коммиты: они остаются достижимы из `main` и могут быть использованы для восстановления ветки.

Перед удалением нужно заново проверить текущую вершину remote и её вхождение в `main`.
Удаление выполняется с compare-and-delete lease по сохранённому SHA; новая работа в ветке
не должна быть удалена поверх архивного снимка. Ветки из `preserved_unmerged` сохраняются.
PR #87 и #90 включены через [интеграционный PR #92](https://github.com/qlolp/TgWatch/pull/92),
даже если GitHub продолжает показывать их отдельными открытыми черновиками.

Для восстановления сопровождающий берёт `name` и `sha` из манифеста, проверяет,
что имя ещё свободно, и создаёт ref на тот же коммит. История сливаемых изменений не переписывается.
Локальные рабочие ветки других участников не затрагиваются.

## Локальные копии и артефакты

Файлы с числовым суффиксом вроде `Example 2.kt`, журналы эмулятора и временные APK
не должны попадать в коммит. Не добавляйте общий ignore для таких имён: он может скрыть
полезную незавершённую работу. Сначала проверьте `git status`; при уборке сохраняйте
неотслеживаемые копии вне checkout вместе с исходными путями, не заменяя существующие файлы.
Подписные ключи и сырые данные физических устройств остаются вне контроля версий.
