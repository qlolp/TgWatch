# 1.17.2 — toolchain and cleanup

Source version `1.17.2`, deterministic Android code `1017002`, target API35.
The production certificate and supported backup/history formats are preserved.

- Built with Gradle 8.14.6, Android Gradle Plugin 8.13.2 and Kotlin 2.4.21,
  updated together; Dependabot now groups these minor updates into one PR.
  The build no longer uses APIs removed in Gradle 9, and the remaining
  compiler warnings in the app sources are fixed.
- A check whose network changed while its probes ran is no longer published as
  UNKNOWN. The previous state, history and outage alert stay as they were, and
  the replacement check on the new network runs one second later.
- Failed diagnostics exports, webhook publications and automation requests log
  their exception class (never addresses, tokens or exception text) instead of
  failing silently.
- CI: a freshly booted emulator that briefly reports `unauthorized` is retried
  until the readiness deadline. The signing setup names which secrets were
  already replaced if an upload stops halfway.
- Finished design notes were removed from `docs/superpowers`. The roadmap records
  why the stuck-webhook abandon and strict Gradle dependency verification were
  not adopted.
