# 1.18.0 — first-run guide and Material You

Source version `1.18.0`, deterministic Android code `1018000`, target API35.
The production certificate and supported backup/history formats are preserved.

- A three-step first-run guide explains what is checked, asks for the
  notification permission and offers to remove battery restrictions. It is
  shown once on a fresh install, can be skipped, and can be reopened with the
  "Setup guide" button. Upgrades from earlier versions do not show it.
- Skipping the guide still asks for the notification permission once, so a
  hurried first launch does not leave outage alerts silently disabled.
- On Android 12+ the background, cards, text and links follow the wallpaper
  (Material You) in light and dark mode. Status and chart colors are unchanged;
  Android 8–11 keep the previous palette.
- Instrumented tests cover the guide flow and check text contrast against the
  background and card colors in both themes.
