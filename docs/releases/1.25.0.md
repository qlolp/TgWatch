# TgWatch 1.25.0

Этот выпуск объединяет расширения мониторинга, автоматизации и подготовки дистрибутивов.

## Мониторинг и приватность

- `MonitorService` дополнительно разделён на компоненты постоянного уведомления и подготовки/публикации Telegram-проверки. Ограниченные пулы, deadlines, отмена, revision isolation, wake lock и порядок завершения сохранены.
- Для Custom HTTPS добавлены точный HTTP-код, подстрока тела до 256 символов, до четырёх JSON string conditions с AND semantics и до восьми приватных request headers. Пять независимых HTTPS-целей и прежние транспортные ограничения сохранены.
- Адреса, критерии, имена и значения headers, webhook/MQTT credentials, токены автоматизации и адрес crash collector остаются в credential-protected storage и не входят в переносимые бэкапы, диагностику и журналы.

## Автоматизация и диагностика

- До пяти независимых webhook-получателей с собственными адресами, форматами, фильтрами, поколениями конфигурации и состоянием доставки. Существующий получатель сохраняет прежние настройки как recipient 1.
- ntfy preset использует обычный HTTPS-получатель и Text format. Отдельный MQTT-адаптер поддерживает MQTT 3.1.1 over TLS, QoS 1, одно короткое соединение на сообщение, capped backoff и отсутствие offline queue.
- Опциональная отправка crash report возможна только на HTTPS collector пользователя после отдельного согласия. Third-party telemetry SDK не добавляется; payload ограничен и не содержит сообщения исключения, адреса, токены, IP, критерии, историю или пользовательские данные.
- Отдельный instrumentation regression закрепляет одновременное создание multi-webhook/ntfy, MQTT и crash controls с разными view IDs; его результат учитывается только после фактического прохождения Android CI.

## Подготовка дистрибутивов

- Добавлен read-only collector для последующей проверки Android/OEM/battery на физических Pixel, Samsung и Xiaomi/HyperOS. Эмуляторные проверки не заменяют эти измерения.
- macOS builder включает pinned Python для arm64 и x86_64 и поддерживает Developer ID signing, notarization и stapling при наличии Apple credentials. Локальная ad-hoc-сборка не называется нотаризованной.
- Документирован independent exact-tag build кандидата F-Droid для 1.24.1. Это историческое evidence только для 1.24.1, а не принятие каталогом и не доказательство воспроизводимости 1.25.0.

Версия 1.25.0, versionCode 1025000. Публикация допускается только после полного CI интегрированного кода,
аудита зависимостей, проверки подписи и обновлений, создания подписанных APK телефона и Wear OS,
