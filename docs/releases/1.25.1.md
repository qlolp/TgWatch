# TgWatch 1.25.1

Исправления надёжности без изменения форматов истории, настроек и ключа подписи.

- Обработка 65 тысяч записей истории выделяет около 1,4 MB вместо 9,2 MB на вызов в измерении host JVM. Это измерение выделений памяти, а не размера кучи Android; исходный Android стресс-тест сохранён. Отдельный тест выполняется с кучей 64 MiB.
- ADB отклоняет ответ, завершившийся после общего дедлайна. Старый, пустой и меняющийся boot ID проверяются с управляемыми часами; реальные CLI-проверки сохранены.
- Кнопка профиля Telegram показывает переведённые названия трёх профилей и собственного интервала вместо `TextValue(...)`.
- Новый изолированный CI использует настоящий Mosquitto 2.0.22 с TLS и паролем: подтверждает PUBACK, точный payload у независимого подписчика и отказ при неверных CA, имени сервера и пароле. Тестовый CA доступен только отдельной JVM; доверие приложения не изменяется.

`main` защищена обязательными PR и десятью CI-проверками; правила действуют для администратора, force push и удаление запрещены. Число обязательных человеческих approvals равно0 для единственного владельца; независимое ревью выполняется до слияния.

Версия 1.25.1, versionCode 1025001. Публикация проходит существующие проверки подписи,
аудитов и обновлений телефона/Wear, дополненные MQTT-проверкой. Набор публичных APK и отчётов не меняется.

Физические Pixel/Samsung/Xiaomi и измерения батареи пока не подтверждены: локальный ADB не ответил на инвентаризацию.
На доступном Mac нет действующего Developer ID и настроенных notary credentials; Apple notarization не выполнена.
Рецепт F-Droid остаётся отключённым до проверки точного тега и review сопровождающего; принятие каталогом не заявляется.
