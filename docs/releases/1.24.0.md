# TgWatch 1.24.0

Выпуск про несколько своих сервисов и общий обзор целей. Telegram, Matrix, WhatsApp Web, региональные
профили и их схемы истории, бэкапов и API сохранены.

- **До пяти своих HTTPS-целей:** кнопка «Добавить свой HTTPS» и «Удалить эту цель» в настройках. У каждой цели свои адрес, условия, интервал, оповещения, плановые паузы и история. Первая цель сохраняет прежний ID `custom` и всю историю; новые получают постоянные ID `custom2` … `custom5` для автоматизации, виджета и вебхука. Удаление стирает адрес, условия и историю этой цели.
- **Обзор всех целей:** каждая добавленная цель с независимым статусом, свежестью последней проверки и переходом к подробностям. Общий процент доступности между сервисами не вычисляется; приватные адреса и health-критерии не показываются.
- **Ожидание публичного ответа после перезагрузки:** восстанавливается только оставшееся время, кнопка показывает «Восстановлено после перезагрузки». Перевод часов не продлевает срок больше 24 часов.

Бэкап с дополнительными целями пишется в формате TGWB v5 (до 24 МиБ, 142 000 наблюдений) и открывается
только 1.24.0+. Без них остаётся v4 и открывается старыми версиями. Восстановление бэкапа без
дополнительной цели удаляет её вместе с приватным адресом. Адреса и условия по-прежнему не попадают
в бэкапы и диагностику.

Версия1.24.0/code1024000. APK используют существующий постоянный ключ; сохраняются проверки подписи
и обновления с опубликованных версий. Публикация APK допускается только после проверок CI, подписи,
аудита зависимостей и подписанных обновлений.
