# TgWatch 1.22.0

Телефон: Android 8.0+ (API26). Самостоятельные часы: Wear OS3+ (API30), отдельное приложение и история.

- На карточке статуса можно показывать страну выхода HTTPS (флаг и локализованное имя). Это страна адреса, через который устройство ходит в интернет, а не GPS. Хранится только ISO-код; сам адрес не сохраняется, не попадает в бэкап и не уходит в вебхук. Переключатель в дополнительных настройках по умолчанию включён, чтобы сохранить поведение 1.21; при смене страны в журнал событий пишется строка `X → Y`.
- Необязательные проверки регионального доступа: YouTube, Gemini, NotebookLM и ChatGPT. Они идут отдельным слоем после проверки Telegram, не меняют статус Telegram, уведомления, виджет и вебхук. Признаки возможного блока: HTTP 451/403, редирект с гео-маркерами в `Location` (редиректы не следуются) или фразы в первых 8 КБ тела ответа. Текст ответа не логируется. При первом переходе в «возможный региональный блок» появляется запись в журнале и строка на карточке статуса.
- Флаги включения egress и региональных пресетов входят в TGWB; исходы проверок и ISO-код остаются локальными для устройства.

Существующие настройки и история сохраняются.

## English

- The status card can show the HTTPS exit country (flag and localized name). This is the country of the address used for outbound HTTPS, not GPS. Only an ISO code is stored; the address itself is never saved, backed up or sent to the webhook. The Advanced toggle defaults to on to keep 1.21 behaviour; an exit-country change is written to the event log as `X → Y`.
- Optional regional-access checks for YouTube, Gemini, NotebookLM and ChatGPT. They run as a separate layer after Telegram and never change Telegram status, notifications, the widget or the webhook. Signals for a possible block: HTTP 451/403, a redirect whose `Location` looks geographic (redirects are not followed), or phrases in the first 8 KB of the response body. Response text is never logged. The first transition into a possible regional block adds an event-log line and a status-card summary.
- Enable flags for egress and regional presets are part of TGWB; probe outcomes and the ISO code stay device-local.

Existing settings and history are preserved.
