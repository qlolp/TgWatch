# 1.17.1 — fewer redraws and wakeups

Source version `1.17.1`, deterministic Android code `1017001`, target API35.
The production certificate and supported backup/history formats are preserved.

- The 15-second health tick no longer re-posts the persistent notification and
  re-sends the home-screen widget when nothing visible changed. A changed status,
  check time, latency, daily uptime or minute-precision age label redraws at once;
  identical content is refreshed at most every five minutes. State publications
  still redraw immediately.
- While the screen is on, the in-process timer runs each check and re-arms the
  wakeup alarm before it fires, so the exact alarm is padded by 60 seconds instead
  of restarting the foreground service every interval. When the screen turns off,
  the padding is removed so the first check during sleep stays on time.
- A refused service start or command from the widget or the Quick Settings tile is
  written to the event log with only its source and exception class — no addresses,
  tokens or exception text.
