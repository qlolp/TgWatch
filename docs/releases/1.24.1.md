# TgWatch 1.24.1

Обновление Android-сборки: SDK 37, AGP 9.2.1, Gradle 9.4.1, Build Tools 37.0.0
и AndroidX Core 1.19.1. Android-модули используют встроенный Kotlin AGP; Kotlin 2.4.21 и JDK 17 сохранены.

Телефон поддерживает Android 8.0+ (minSdk 26); targetSdk остаётся 36. Отдельное приложение
Wear OS сохраняет compile/targetSdk 35 и minSdk 30 (Android 11+).

Несколько HTTPS-целей, обзор целей, ожидание ответа после перезагрузки и все остальные
возможности [1.24.0](1.24.0.md) сохранены. Форматы истории, бэкапов и API не менялись.
При установке поверх совместимо подписанной версии удалять приложение и данные не нужно.

Проверка постоянного сертификата адаптирована к формату apksigner 37; чужой ключ,
неизвестные или дополнительные сертификаты по-прежнему отклоняются.

Версия 1.24.1, versionCode 1024001. Выпуск допускается после unit/instrumentation,
lint, аудита зависимостей, проверки постоянного сертификата и двух подписанных обновлений:
с неизменного 1.10.47 и с последнего стабильного 1.24.0 без очистки данных.
Подписанные APK телефона и Wear OS публикуются вместе с SHA-256, SBOM и отчётами аудита.
