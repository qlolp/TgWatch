# TgWatch 1.26.0

Сводка смены на главном экране и корреляция сбоев с сменой egress/сети — без новых проб и без изменения форматов истории, настроек и ключа подписи.

- На главном экране появляется карточка «Что изменилось» за последние 24 часа: статус целей, geo-ограничения региональных сервисов, смена страны egress и VPN-маршрута.
- Для сбоев Telegram показывается совпадение по времени со сменой egress или сети (окно ±15 минут). Это временная близость, не утверждение причинности.
- Текст карточки можно отправить через системный Share (в том числе в клиенты ntfy и другие получатели текста).
- Политика чистая (`ChangeSummary`) и покрыта JVM-тестами; UI обновляется тем же минутным тикером, что и история.

Версия 1.26.0, versionCode 1026000. Публикация проходит существующие проверки подписи, аудитов и обновлений телефона/Wear. Набор публичных APK и отчётов не меняется.

Внешние этапы без изменения: физическая OEM/battery-матрица, Developer ID/notarization, принятие каталогом F-Droid.
