Статус: подготовлено, выпуск не заявлен. Файлы заполняются по результатам прогонов CI
и подписанных обновлений; описание сценария не является отчётом о его выполнении.

| Проверка | Что покрывает | Результат |

| Подписанное обновление с предыдущего опубликованного релиза | сохранение истории и настроек без удаления | ожидает CI |
| Публикация по тегу `v1.14.0` | preflight, перепроверка APK, иммутабельность | ожидает владельца |

IPv6-only сеть, согласие на `SCHEDULE_EXACT_ALARM` на Android 13+.
