# TgWatch 1.20.1

Телефон: Android 8.0+ (API26). Самостоятельные часы: Wear OS3+ (API30), отдельное приложение и история.

- Экономичный режим дополнительных целей выключен по умолчанию. Он учитывает экран, системное энергосбережение и низкий заряд без питания. Реальный интервал виден в интерфейсе; настройки Telegram сохраняют прежний смысл. Оценка экономии требует измерений на устройстве: [протокол проверки](https://github.com/qlolp/TgWatch/blob/v1.20.1/docs/power-validation.md).
- Свой HTTPS может проверять ожидаемый HTTP-код и простое поле JSON. Ответ ограничен32KiB и глубиной10; адрес и условия остаются в credential-protected хранилище и исключены из переносимых бэкапов и публичных карточек. Пустые условия сохраняют прежнюю проверку доступности.
- Отдельный JSON v2 добавляет свежесть и heartbeat не чаще пяти минут, используя уже выполненные проверки. Новых будильников и соединений мониторинга для heartbeat нет. Текстовый формат и JSON v1 сохраняются. [Пример Home Assistant](https://github.com/qlolp/TgWatch/blob/v1.20.1/docs/examples/home-assistant/tgwatch-heartbeat.yaml) снимает доступность по локальному TTL при прекращении доставки.
- RU/EN-тексты берутся из ресурсов Android, включая фоновые уведомления до открытия главного экрана. Карточка фиксирует язык для предпросмотра, текста и PNG. Диагностика известных ошибок остаётся понятной; общий сбой показывает класс исключения без его потенциально приватного сообщения.

Настройки и история существующей установки сохраняются. Формат зашифрованного экспорта всех целей — TGWB v3, Telegram-only v2 по-прежнему доступен. Интеграции и дополнительные условия включаются только пользователем. Принятие F-Droid и измеренная экономия батареи на конкретной прошивке не подразумеваются.

## English

- Optional secondary-target power saving uses screen, power-saver and unplugged low-battery state. Actual intervals are visible; the mode defaults off.
- Custom HTTPS supports an expected HTTP status and a small JSON field condition, with a32KiB/depth10 response bound. Endpoint and conditions stay private and outside portable backups and public cards. Empty conditions preserve the existing reachability check.
- Opt-in JSON v2 carries freshness and a five-minute heartbeat from existing measurements, without new wakeups. TEXT and JSON v1 remain available. The supplied Home Assistant example expires reachability using a local delivery TTL.
- Android resources now resolve RU/EN presentation at its own context, including background notifications. Share preview, text and PNG use one frozen resource document. Generic diagnostic errors expose exception classes rather than potentially private messages.

The phone and standalone watch remain separate applications. Existing settings/history and signing continuity are preserved. See the versioned verification evidence for executed checks; physical-device battery savings and F-Droid acceptance are not claimed.
