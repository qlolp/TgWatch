# TG Monitor 1.13 — automation, extras, Glance

Builds on 1.12 (daily summary + English UI).

- **Automation API** for Tasker/Termux: permission-gated broadcasts, status content provider, documented in `docs/automation.md`.
- **Extra service probes** (opt-in): Matrix, WhatsApp Web, custom HTTPS URL — diagnostics only; Telegram classification unchanged.
- **Webhook alerts** (opt-in ntfy HTTPS URL) on status changes.
- **Doze miss counter**: estimates overdue checks while the screen is off.
- **Glance widget** alongside the classic RemoteViews widget.
- **Notification progress** bar for last-day availability percentage.
- **SQLite history mirror** (`HistoryDb`) dual-written for a future cutover; CSV remains source of truth.
- **MTProto `assets/dc.json`** optional endpoint hint with bundled fallback.
- **targetSdk 35**, Compose/Glance/coroutines dependencies, `.editorconfig` + ktlint (non-blocking).
- F-Droid packaging notes under `docs/fdroid.md` / `fastlane/metadata`.

Backup TGWB v2 settings gain webhook/extra-service keys; older clients reject unknown keys (same forward-only rule as 1.12).

Local `versionName` 1.13; CI `versionCode` remains `GITHUB_RUN_NUMBER + 100` (release-policy).
