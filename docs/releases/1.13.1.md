# 1.13.1 — fixes from the code audit

Source version `1.13.1`, deterministic Android code `1013001`, target API35.
This is a prepared release description; it does not claim publication.

- Refresh the status right after the screen turns on when the last check in
  this process is more than 30 seconds old, so unlocking after a long
  screen-off interval no longer shows an old result.
- Re-arm the watchdog alarm after every completed check: it now wakes the
  device only when checks stop arriving, instead of every 3 minutes.
- Fix the stale-result indicator: it is judged against the interval each
  result scheduled (profile, screen-off sleep and offline backoff included).
- Boot/time broadcasts and widget taps are handled by non-exported receivers;
  other apps can no longer trigger them.
- Stop retrying the one-time settings move to device-protected storage after
  it has succeeded.
- Add a regression test that intercepted Telegram hosts classify as
  Telegram unavailable.
