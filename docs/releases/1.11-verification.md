## Development upgrade и cold replay

Сборка из published-main source `c345829` (debug 1.10/code 10) обновлена до 1.11/code 12
с общей development-подписью через `adb install -r -g`, без очистки/удаления между версиями.
Сохранены 14 настроек вне часовых ключей, effective legacy hours 23–07 и все прежние CSV observations;
`upgrade-policy.py verify` подтвердил новую строку с timestamp свежей проверки.

После force-stop вручную записан raw published `restore.pending`, затем запущен новый
реальный Application process. Удалены оба journal names, monitoring выключен, `last_*`
очищены; сохранены independent alerts, минуты 1320/420 (22–07), журнал и точная history row.
Все assertions завершились успешно. Это проверка development source upgrade и replay,
**не** обновление production APK или доказательство production certificate continuity.

После 29/29 PASS при установке в AVD без KVM наблюдался Launcher ANR; функциональные
assertions прошли, TgWatch fatal не зафиксирован. Этот прогон не подтверждает полный
smoke, API 29, физическую батарею или OEM background behavior.
