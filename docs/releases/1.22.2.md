# TgWatch 1.22.2

Телефон: Android 8.0+ (API26). Часы: самостоятельный Wear OS 3+ (API30), собственная сеть и история.

- Экспорт, проверка бэкапа и предпросмотр CSV переживают пересоздание экрана без запуска
  второго задания. Предпросмотр хранится только в памяти до пяти минут; пароль и данные
  не помещаются в сохранённое состояние Activity.
- Проверка документов и экспорт получили отмену и общий тайм-аут 120 секунд. Сроки
  проверяются по прошедшему времени, включая сон устройства. Если файловый провайдер
  завис, новая операция ждёт фактического завершения старой, а поздний результат отбрасывается.
- После отмены или тайм-аута экспортированный файл может быть неполным. Уже подтверждённая
  транзакция восстановления не прерывается отменой и сохраняет восстановление из журнала.
- Файл дополнительной сетевой статистики ограничен по размеру и числу строк. Счётчики
  используют ограниченные Long; перевод часов назад удаляет будущие дни из календарного окна.
- Пробы с одинаковыми подписями сопоставляются по отдельным заданиям, поэтому разные
  адреса и занятый дубликат больше не подменяют результат друг друга.

Сохранены все возможности 1.22.1, включая региональные профили, сроки истории 7/30/90 дней,
TGWBv4 и плановые паузы. Форматы истории и бэкапов в этом исправлении не меняются.
Существующие настройки и история сохраняются. Подпись и обновление без удаления данных
проверяются релизным workflow перед публикацией. Подготовка предыдущей версии читает
свежую иерархию её UI без ожидания неподвижного экрана; запуск выполняется настоящими
кнопками, затем проверяются foreground-сервис и сохранённая новая запись.

## English

- Backup export, validation and CSV previews survive screen recreation without duplicate jobs.
  Previews remain in process memory for at most five minutes; saved Activity state contains no
  password or decrypted payload.
- Document operations support cancellation and a shared 120-second deadline, including time
  spent asleep. A stuck provider keeps its physical worker slot until it actually returns;
  cancelled or late results are discarded.
- A cancelled or timed-out export may be incomplete. A confirmed restore transaction remains
  non-cancellable and retains durable journal recovery.
- Auxiliary network statistics have byte/row limits, bounded Long counters and future-day
  pruning after clock rollback. Probes with identical labels retain their own task results.
- All 1.22.1 features, TGWBv4 and existing settings/history remain supported. This patch adds
  no new data format. The release workflow checks production signing and data-preserving upgrades.
