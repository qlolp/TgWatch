# TgWatch 1.22.1

Включает возможности исходников 1.22.0. Их публикацию остановил дополнительный HTML-отчёт Gradle;
в 1.22.1 отключена только его генерация. Все проверки качества, подписи и обновления сохранены.
Тег v1.22.0 не изменялся, APK этой версии не публиковались.

Телефон: Android 8.0+ (API26). Часы: самостоятельный Wear OS 3+ (API30), собственная сеть и история.

## Региональная доступность

- На главном экране есть отдельная кнопка региональных сервисов. YouTube, Gemini, Notebook,
  Antigravity и ChatGPT/dots включаются независимо, по умолчанию выключены.
- Проверяется публичный HTTPS-сайт с текущего телефона. «Сайт отвечает» не подтверждает вход,
  воспроизведение видео, генерацию или работу dots/IDE. CAPTCHA, вход, ограничение частоты,
  ошибки сети и неопределённые ответы показаны отдельно вместе с возрастом и HTTP-кодом.
- Предупреждение требует двух явных региональных ответов в одном подключении с интервалом
  не меньше 15 секунд. Флаг страны и обычный 403/451 не являются доказательством блокировки по IP.
  Регион аккаунта и правила самого сервиса также могут влиять на результат.
- Обычно проверки идут раз в 5 минут, при выключенном экране/экономии заряда — раз в 10 минут;
  ограничения Android могут их задержать. Работает существующая фоновая служба, в том числе без Telegram.
- Отдельный системный канал, общие тихие часы/приглушение/DND и региональные плановые паузы.
  Повторные предупреждения подавляются; ошибка сети не объявляется восстановлением.
- Смена сети, изменения профилей и восстановление данных исключают публикацию старого ответа.
  Восстановление выключает все региональные профили и очищает их локальное состояние.

## Страна и компьютер

Флаг страны дополнен названием, источником Cloudflare и возрастом. Есть ручное обновление.
Результат другой сети, предыдущей загрузки телефона, после перевода часов или неудачного обновления
не показывается текущим. IP-адрес не сохраняется. Раздельная маршрутизация может давать Cloudflare
и самим сервисам разные выходы: страна остаётся контекстом, а не автоматическим вердиктом.

Утилита Python без дополнительных библиотек измеряет отдельное подключение Mac. Есть разовый режим,
наблюдение в открытом Terminal, безопасный JSON и опциональные локальные уведомления. Скрипт запуска
находится в `tools/TgWatch-services.command`. Автозапуск не устанавливается.
Ручная закладка браузера проверяет видимую ошибку в текущей сессии без cookies, запросов и экспорта страницы.
[Инструкция](../regional-services.md).

## История и качество

Выпуск включает накопившиеся изменения main: пресеты публичных JSON status pages и пути условий,
историю 7/30/90 дней с агрегатами и явными пробелами, TGWBv4 с настройкой срока хранения,
плановые паузы исторических целей и схему диагностики 5. Новые региональные профили не меняют
существующие TargetId, истории, API и форматы этих целей.

Исправлены три регрессии Android-проверок (фикстура срока хранения, схема отчёта и 48dp при крупном
шрифте), а также проверочный скрипт обновления: теперь он читает поддерживаемые реестрыv3/v4,
продолжая отклонять неизвестные форматы. Добавлены общие примеры классификации Android/Mac,
проверки TLS, перенаправлений, размера ответа, отмены и запоздалой публикации.

Постоянный сертификат подписи сохраняется. Обновление установки с этим ключом сохраняет данные;
утраченный debug-ключ версии 1.6 по-прежнему нельзя восстановить этим выпуском.

## English

- Independent optional public profiles for YouTube, Gemini, Notebook, Antigravity and ChatGPT/dots,
  in the existing phone service, including regional-only monitoring.
- Two explicit regional responses at least 15 seconds apart on one connection are required for an alert.
  Generic 403/451, authentication, CAPTCHA and network failures are separate. Public-site responses
  never certify playback, inference, account or IDE readiness, or an IP-only cause.
- Current boot/network-bound exit-country name, flag, Cloudflare source, age and manual refresh.
- A separate Mac Python companion and manually invoked local browser helper; no account credentials,
  cookie access, page export or installed startup agent.
- Existing main changes include status-page JSON presets, 7/30/90-day retention/rollups, TGWBv4 and
  historical-target maintenance windows. CI regression fixes preserve the existing quality/release gates.
- Existing permanent signing identity and data-preserving upgrade policy remain in place.
