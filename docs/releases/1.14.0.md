# 1.14.0 — alert actions, quieter summary, scalable chart

Source version `1.14.0`, deterministic Android code `1014000`, target API35.
This is a prepared release description; it does not claim APK publication or
F-Droid acceptance.

- Telegram-down and partial-reachability notifications have two actions.
  "Check now" runs a check through the same service request as the status
  notification's "Check" action. "Mute for 1 hour" silences alert sound and
  vibration for 60 minutes through the quiet-hours path: alerts are still
  posted, silently. The tapped alert is dismissed and the mute is logged. The
  deadline is kept in device settings, survives a restart of the app, is not
  part of the portable backup, and ends early if the clock is moved back. The
  main screen shows "Alerts muted until …" while monitoring runs.
- The scheduled daily summary is not posted while monitoring is off. Its alarm
  stays armed, and the "Show now" preview works regardless.
- The response-time chart grows with the system font size. Its labels were
  already sized in sp; now the view adds height for them instead of shrinking
  the bars, keeps descenders inside the view, and drops the "60 min ago" label
  when it would overlap the "now · avg" label. At the default font size the
  chart keeps its 120 dp height.

The backup format is unchanged from 1.13.3: TGWB v2 with JSON payload
`formatVersion=2`. See [backup details](../backup.md).
