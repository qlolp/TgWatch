# 1.19.0 — "Telegram is slow" notice and app-icon shortcuts

Source version `1.19.0`, deterministic Android code `1019000`, target API35.
The production certificate and supported backup/history formats are preserved.

- A quiet "Telegram is slow" notice appears when Telegram answers but even the
  fastest MTProto server takes longer than one second for three checks in a row.
  It clears once a check is faster than 0.6 seconds, repeats at most every
  30 minutes, honours quiet hours and the one-hour mute, has its own switch and
  notification channel, and the switch is included in backups. Older backups
  restore with the notice enabled.
- Long-pressing the app icon offers "Check" (starts a check without opening the
  app) and "Mute" (silences alerts for an hour, like the outage notification's
  action). The shortcut activity is not exported; launchers start shortcuts as
  the app itself.
